# Product Catalog JS

Интерактивный каталог товаров с динамической карточкой, корзиной и адаптивной версткой. Проект разработан на чистом HTML, CSS и JavaScript без использования фреймворков.

**Демо:** [https://kater-g.github.io/product-catalog-js/](https://kater-g.github.io/product-catalog-js/)

## Ключевые возможности

- **Каталог с пагинацией:** Порционная загрузка карточек через кнопку «Показать ещё» и ленивая загрузка изображений (`loading="lazy"`) для оптимизации производительности.
- **Адаптивные фильтры:** Панель фильтров сворачивается в аккордеон на мобильных устройствах и синхронизируется с размером окна браузера.
- **Умная корзина:** Сохранение состояния в `localStorage`, привязка количества к ID варианта товара (фасовке) и интерактивный UI счетчика.
- **Динамическая страница товара:** Рендер контента из JS-объекта по ID из URL с автоматическим обновлением цены и артикула.

## Стек

- JavaScript, HTML, CSS
- Модульная архитектура: разделение логики (`shared.js`), данных и представления
- Без фреймворков, библиотек и сборки: проект запускается открытием index.html
